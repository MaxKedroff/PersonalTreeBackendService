# 📘 UDV Team Map — Backend

Серверная часть веб-приложения для визуализации организационной структуры компании **UDV Group**.  
Реализована на стеке **ASP.NET Core**, **PostgreSQL** с использованием архитектуры **ONION**.

---

## 🚀 О проекте

**UDV Team Map** — это инструмент, который помогает сотрудникам быстро находить коллег, понимать иерархию подразделений и поддерживать актуальность данных.  
Backend отвечает за хранение, обработку и безопасную передачу данных о сотрудниках и структуре компании.

### 🔍 Основные задачи backend:
- Обеспечение **надёжного хранения** данных в PostgreSQL
- Реализация **бизнес-логики** управления структурой
- Предоставление **REST API** для фронтенда
- Контроль доступа через **ролевую модель** 
- Поддержка **масштабируемости** и **тестируемости**

## 🧱 Архитектура: ONION

Проект построен по принципам **ONION-архитектуры**, где ядро не зависит от внешних слоёв.

### 📦 Слои проекта:

#### 1. `Domain`
- Бизнес-сущности: `User`, `Hierarhy(в разработке)`
- Интерфейсы репозиториев: `IUserRepository`
- DTO, исключения(в разработке), бизнес-правила

#### 2. `Infrastructure`
- Реализация репозиториев через EF Core
- Настройка БД, миграции
- Интеграция с внешними сервисами (LDAP)

#### 3. `Application`
- Сервисы бизнес-логики: `AuthService`, ``UserService``
- Валидация команд и запросов

#### 4. `API`
- Контроллеры ASP.NET
- Авторизация через JWT
- Обработка ошибок
- Swagger UI
